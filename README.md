# Java OOP Project

A Java project demonstrating core Object-Oriented Programming concepts through practical examples and exercises.

## 📌 Project Overview

This repository contains Java implementations covering fundamental Object-Oriented Programming concepts, along with a larger OOP project and UML documentation.

The project was developed to practice designing and implementing Java programs using object-oriented principles.

## 🧠 Concepts Covered

The repository includes examples of:

- Basic Class Definition
- Object-Oriented Programming
- Interfaces
- Aggregation
- Combining Multiple OOP Concepts
- UML Diagrams
- Java Project Structure
- Maven Project Configuration

## 📂 Project Files

### Java Examples

- `Define_Basic_Classes.java`
  - Demonstrates defining basic Java classes and working with objects.

- `Implement_an_Interface.java`
  - Demonstrates implementing interfaces in Java.

- `Aggregation.java`
  - Demonstrates the aggregation relationship between classes.

- `Putting_It_All_Together.java`
  - Combines multiple Object-Oriented Programming concepts into a complete example.

### Project Files

- `pom.xml`
  - Maven project configuration.

- `UML Diagram Components.pdf`
  - UML-related project documentation.

- `OOP_Project.rar`
  - OOP project archive.

- `Project OOP.rar`
  - Additional OOP project archive.
